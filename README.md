# AI-Alert-System
## 🚀 Project Overview
This is a simple security system that:
- Uses mobile camera
- Captures image
- Gets location
- Sends alert to Gmail

---

## 🔥 Features
- 📱 Mobile camera access
- 📸 Image capture
- 📍 Live location
- 📩 Email alert

---

## 🧱 Tech Used
- HTML (Frontend)
- JavaScript
- Node.js (Backend)
- Nodemailer (Email)
